 Steps on how to successfully run the project 

 1. Clone the repo to your local machine
 2. Make sure maven actually builds successfully for all dependencies to be installed
   > On the maven console run maven clean install. I used intellij as my IDE, the maven console is on your left panel.
 3. Run the ProviderApplication Springboot starter application.
 4. Use the postman collection on the project root to test.
